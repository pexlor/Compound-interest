# 复利簿（本地版）

一个在本机运行的全资产记录与未来收益测算工具。

## 已实现功能

- 记录股票、基金、货币基金、存款、公积金和固定资产
- 支持本地用户注册、登录和退出
- 新注册用户从空账本开始，不会自动生成示例资产
- 不同用户的资产严格分开保存
- 股票按代码读取历史行情，支持国内股票与美股代码
- 基金支持国内基金代码及 QQQ、VOO、SPY 等美股 ETF
- 基金支持按月、按周、按年首个交易日或每个交易日定投，并自定义单次金额
- 股票和基金收益率支持按近 1、3、5、10 年历史区间计算
- 每天北京时间 04:10 预计算数据库内市场资产的 1、3、5、10 年收益，服务启动时也会在后台预热一次
- 用户读取当天缺失的市场收益时自动补算并保存；历史不足时显示实际使用的数据天数
- 9 种外币的最近 10 年历史汇率保存在 R2 的 `exchange-rates/history.json`，并幂等导入 D1 历史表
- 服务启动时先补齐汇率文件到当前可用日期，再导入数据库并预热市场收益
- 每天北京时间 00:00 增量同步汇率历史；最新汇率和美股历史收益计算优先读取 D1
- 货币基金按每万份收益折算年化收益率
- 存款、公积金支持手动输入年利率
- 录入金额时支持人民币、美元、港币、欧元、日元、英镑等 10 种常用货币
- 总资产、资产配置和收益预测按最新央行参考汇率统一折算为人民币
- 新增、修改或删除资产，以及手动刷新汇率时，自动记录当天的总资产快照
- 资产历史按记录时的汇率折算为人民币；同一天多次变更只保留最后一次结果
- 支持 1、3、5、10 年复利收益预测
- 用户、密码哈希、登录会话和资产记录均保存在本机 SQLite 数据库中

## 本地启动

需要先安装 [Node.js 22](https://nodejs.org/) 或更高版本。

macOS 可以直接双击项目目录中的 `start-local.command`。脚本会自动检查运行环境、首次安装依赖，并在服务启动后打开浏览器。

Linux 可以执行一键启动脚本。脚本每次会先停止上一次启动的实例，再构建并在后台启动服务。默认监听所有网卡的 3000 端口，并将本地数据库保存在 `.wrangler/state`：

```bash
./start-linux.sh
```

需要修改监听地址或端口时，可以使用环境变量，例如：

```bash
APP_HOST=127.0.0.1 APP_PORT=3100 ./start-linux.sh
```

启动完成后可以直接关闭终端。后台进程号保存在 `.wrangler/fulibu.pid`，运行日志保存在 `.wrangler/fulibu.log`。再次执行脚本即可重启服务。

在当前项目目录打开终端，然后执行：

```bash
npm install
npm run dev
```

看到 `Local: http://localhost:3000/` 后，在浏览器打开：

<http://localhost:3000/>

停止运行时，在终端按 `Ctrl + C`。

## 本地数据与网络

- 用户和资产记录保存在项目目录下的本地 SQLite 数据库，不会自动上传到第三方账户。
- 密码不会明文保存，使用随机盐和 PBKDF2-SHA256 哈希后写入数据库。
- 登录状态使用仅服务端可读的本地 Cookie，有效期 30 天；点击“退出”会立即删除当前会话。
- `.wrangler/` 是本地数据库和运行缓存目录，已从 Git 中排除。
- 股票和基金收益率需要联网读取腾讯证券、东方财富的公开行情接口。
- 首次建立汇率历史文件时会按年度窗口读取 Frankfurter 最近 10 年数据；以后只在启动、北京时间 00:00 或手动刷新时补齐。
- 汇率历史在 R2 文件和 D1 中都只保留滚动 10 年。重复启动使用 `INSERT OR IGNORE` 导入缺失记录，不会覆盖已有历史值。
- 页面最新汇率和美股 USD/CNY 历史换算优先读取 D1；数据库缺失时才访问 Frankfurter 并回填数据库。
- 若快照涉及的任一外币没有可用汇率，本次资产操作仍会成功，但不会保存不完整的历史总资产快照。
- 若行情接口暂时不可用，已有资产记录和手动利率计算仍可使用。
- 行情调试日志统一使用 `[market-return]` 前缀，包含缓存命中、缺失回填、旧数据回退和预热汇总，不记录用户身份或 Cookie。
- 汇率同步日志统一使用 `[exchange-rate-history]` 前缀，包含抓取窗口、R2 条件写冲突、D1 新增数、同步耗时和失败原因。

```bash

npm run dev

```

## 收益预测说明

股票和基金使用指定历史区间的收益率进行年化外推；配置定投的基金会把每笔未来投入按剩余持有时间计入复利，国内基金按上海时区、美股 ETF 按纽约时区识别交易日（周末除外）。存款和公积金按录入利率复利计算；固定资产默认不计算收益。外币预测使用当前最新汇率并假设未来汇率保持不变，不包含汇率波动预测。所有预测仅用于个人资产规划参考，不代表实际收益或投资承诺。
