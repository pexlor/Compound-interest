# 人民币口径市场收益设计

## 目标

所有自动同步的市场收益率统一使用人民币口径。人民币资产维持现有计算；美元计价的美股在价格收益基础上加入同期 USD/CNY 汇率变化，避免将美元收益与人民币基金收益直接混合比较。

## 范围

- 美股代码继续由现有腾讯行情路径获取起止价格。
- 国内股票、人民币基金和货币基金不做汇率换算。
- 不新增数据库表，不保存历史汇率。
- 不改变资产金额、当前汇率或组合预测的其他逻辑。

## 数据流

1. 行情处理器按现有逻辑确定美股的起止价格和实际日期。
2. 分别查询起止日期前七天至该日期的 USD/CNY 历史汇率。
3. 每个窗口选择不晚于对应行情日期的最新有效汇率，以覆盖周末和汇率市场休市。
4. 使用人民币计价后的起止价值计算区间收益和年化收益。
5. 市场 API 的 `annualRate` 和 `periodReturn` 继续使用现有字段，但其含义统一为人民币收益。

计算公式：

```text
人民币区间收益 = (期末价格 * 期末 USD/CNY) / (期初价格 * 期初 USD/CNY) - 1
人民币年化收益 = (人民币期末价值 / 人民币期初价值)^(365 / 实际天数) - 1
```

## 汇率来源

历史汇率使用 Frankfurter 的央行参考汇率接口。每个行情日期只查询一个七天小窗口，不下载整段年度汇率。现有市场结果缓存继续缓存换算后的最终结果，因此相同代码和回看周期在缓存有效期内不会重复查询行情或汇率。

## 错误处理

- 历史汇率请求失败、响应格式异常或窗口内没有有效 USD/CNY 汇率时，市场 API 返回明确错误。
- 不允许静默退回美元收益，因为这会重新造成混合币种口径。
- 国内资产不依赖历史汇率服务，汇率服务异常不影响其收益同步。

## API 可观察行为

- 美股返回的 `annualRate` 和 `periodReturn` 变为人民币口径。
- `source` 标明腾讯美股行情和历史汇率调整。
- 起止日期仍是行情交易日，不替换为汇率数据日期。
- API 路径和前端调用方式不变。

## 测试

- 美股价格上涨但美元贬值时，验证返回人民币收益而非美元收益。
- 汇率日期缺失时，验证选择窗口内最近的前一有效日期。
- 历史汇率不可用时，验证返回错误而非美元收益。
- 国内股票和基金验证不触发历史汇率请求。
- 现有一年、十年、缓存、超时和成立日回退测试继续通过。
- 使用真实 QQQ 和 021000 数据复算，确认一年收益均为人民币可比口径。
