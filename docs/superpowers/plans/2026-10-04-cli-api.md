# CLI 后端接口实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 为仅调用 HTTP 的 CLI 提供可认证、可查询、可预览、可追踪的资产读写接口。

**Architecture:** 保留现有 Cookie 网页接口并增加用户级 Bearer 令牌。读写计算共用 Go 服务层；写入、版本检查、幂等结果与日志在同一 SQLite 事务中完成。CLI 与 Skill 在后续独立计划中实现，本计划只交付后端接口和接口文档。

**Tech Stack:** Go 1.24、net/http、database/sql、现有 SQLite 驱动、httptest。

**Spec:** `docs/superpowers/specs/2026-10-04-cli-skill-design.md`

## Global Constraints

- CLI 只能通过 HTTP 接口访问后端，不能直接访问 SQLite。
- 使用 CLI 与 Skill，不增加 MCP。
- 保留网页 Cookie、现有 JSON 字段和既有请求的兼容性。
- 金额数据库存储单位为分；现有主货币单位写入请求继续兼容，新增契约明确单位。
- 用户身份由认证确定，不允许请求指定另一个用户。
- 第一版不提供交易流水、实际交易执行或任意 SQL 功能。
- 本计划不生成 CLI 二进制、不安装 Skill、不修改部署或真实用户数据。

## Review Focus

- 无效 Bearer 不能回退到有效 Cookie，读令牌不能触发业务写入。
- 空字段、null、零金额、负数量、未知币种和尾随 JSON 必须有明确校验结果。
- 并发修改、重试和复用不同内容的请求编号不得覆盖或重复写入。
- 归档记录必须从当前汇总、退休计算、行情刷新和后续快照一致排除。
- 行情部分失败不能被表述为全成功；dry-run 不能改变数据、历史或操作日志。

## 统一契约

- Bearer 写请求使用 `Idempotency-Key`；修改已有记录携带整数 `version`。相同编号与相同请求重放原响应，不同内容返回 HTTP 409。
- 写接口支持 `?dryRun=true`。预览经过同样的参数和权限校验，返回 `before`、`after`、`dryRun: true`，不提交事务。
- 新增成功为 201，修改为 200；401 未认证、403 权限不足、404 当前用户下不存在、409 幂等或版本冲突、400 参数错误。
- 新增错误包含稳定的 `code` 和可读 `error`；不输出数据库错误或凭据。
- 金额输出保留现有整数字段，并在新增响应中标注 `moneyUnit: "minor"`；summary 使用 `totalCnyMinor`、`valueCnyMinor`。
- Bearer 访问现有永久删除资产及目标明细接口返回 403；网页登录保持现有行为。
