# 数据导出验收

页面顶部新增“数据导出”按钮，可勾选资产清单、股票/基金每日行情、历史年化、资产每日快照及汇率历史。支持全部当前资产或指定持仓、开放或封闭的日期范围。单类 CSV，多类 ZIP；空历史保留表头。

下载通过 `GET /api/export`，支持会话和只读 API 令牌。所有个人数据按用户隔离，公共行情按本人所选资产对应证券去重。导出事务只读取本地数据库，不抓取行情、改写估值或生成额外快照。中文表头、UTF-8 BOM、原币种主单位金额、百分数利率，文本公式前缀保护。ZIP 附各文件行数与单位说明。接口参数见 `go-backend/docs/cli-api.md`。

实际浏览器测试发现登录后 `assetsLoading` 无法结束，一并修复：身份变化后重新读取 dashboard，取消旧请求；401 清除失效登录态，旧账号的退休目标响应不再覆盖新账号。
