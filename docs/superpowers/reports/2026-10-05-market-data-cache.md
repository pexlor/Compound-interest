# 行情缓存执行与验收记录

## 实现

- SQLite 持久化实际交易日行情、报价、覆盖范围、每日四档年化、个人日快照和任务状态；新增表纳入可选 MySQL 备份。
- 读取先返回缓存。首次缺失后台补齐，已有缓存过期时保留有效结果并后台更新。同证券请求合并，限制并发，失败重试与冷却。
- 默认保留近十年采集范围，基金真实分页；基金成立不足的区间使用实际可用历史并标示数据范围，来源截断不当作完整历史。
- 日常回取近期 30 天，每周完整校验。发现历史复权调整时重新拉取整个保留范围，再原子更新行情和四档年化。
- 年化测试区间为 365、1095、1825、3650 天；计算沿用实际间隔 / 365.25 的复利年化。货币基金优先使用来源公布的七日年化。未来新增本金继续不参与复利。
- Asia/Shanghai 每日 09:30、17:00 刷新；错过的任务重启后补执行，多个时段合并采集。保留已有 05:00 快照和 09:16 汇率任务。
- 首屏使用 dashboard 内的缓存结果；缺失时显示计算状态，迟到请求不能覆盖已切换区间。
- 认证接口 `/api/market/cache-status` 展示当前用户持仓对应证券的缓存覆盖、派生区间、同步状态与任务状态，个人快照按用户隔离。
