# 现有预测引擎性能优化（2026-10-07）

本次优化沿用 joint-block-v1：默认5000条路径、每条固定种子、联合三个月历史抽样、收益中心、现金流与退休目标口径均保持原样。没有更换历史窗口算法，也没有降低路径数。仅优化后端引擎，前端刷新和跨请求结果缓存不在本次范围。

## 实现

- 预计算每个检查点的日期差与通胀目标，全部路径复用。
- 相同月内时间比例共享资产及外汇收益因子表，避免路径循环重复执行指数函数。每个请求最多使用8MiB因子表，超出时直接使用原计算表达式；不缓存账户预测结果。
- 在准备阶段把资产及收入币种转换为数组索引，内层循环不再通过字符串map查询汇率。
- 复用随机源、余额与汇率缓冲区。每条路径仍重设相同种子，随机抽样次数与顺序不变。
- 分位数样本预分配容量，避免逐路径追加引起重复分配；相同证券和基准的月收益只解析一次。
- 所有共享数据仅限当前请求，预计算阶段检查请求取消。

## 本机实测

Apple M5 / darwin arm64，10项合成混合资产（人民币、美元、港币、固定利率和固定资产），包含外币收入、月内多笔到账和退休目标。每项运行3次，以下为耗时中位数。原始模型准备和路径循环冻结在测试参考实现中；输入完全相同。

| 期限 | 优化前 | 优化后 | 加速 |
| --- | ---: | ---: | ---: |
| 1年 | 63.5ms | 36.8ms | 1.7倍 |
| 10年 | 320.4ms | 62.3ms | 5.1倍 |
| 30年 | 862.5ms | 115.2ms | 7.5倍 |

10年单次总分配约33.47MB降至2.43MB，分配次数约15641降至2902。这里是本机模拟函数的合成输入基准，不是服务器实际账户API耗时。服务器SSH密码认证未通过，无法完成新的服务器复测；应用没有部署，运行版本没有切换。

## 验证

- 优化前后完整结果DeepEqual：月中、月末、闰日；1/10/30年；空资产、固定利率、混合币种、仅外币收入、短历史回退；默认5000路径；3000项资产触发收益表预算回退。
- 对收益表按共享数组去重计算实际占用，验证0/1/15000/8MiB预算，确保不会超额分配。
- 已取消请求返回context.Canceled；原每32条路径检查仍保留，运行中取消未新增专项测试。
- 优化前5000路径分配上限测试失败（15642次，大于3000），优化后通过。
- `go -C go-backend test ./... -count=1`、`go -C go-backend vet ./...`及`go -C go-backend test -race ./...`通过。race构建有macOS CGO链接器LC_DYSYMTAB警告，测试退出成功、未报告数据竞争。
- 独立代码审查通过；测试参考实现不参与生产构建。

复测命令：`go -C go-backend test ./internal/service -run '^$' -bench BenchmarkForecastPerformance -benchtime=1x -count=3`。
